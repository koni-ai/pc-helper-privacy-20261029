# 내 PC 도우미 개인정보 처리방침

시행일: 2026-10-30

## 목적과 이용 대상
이 앱은 앱 소유자 한 명이 본인 Discord DM과 개인 PC의 전용 Aside 대화 사이에서 문장을 주고받고, 지원되는 질문·일회성 권한 요청에 직접 응답하기 위한 비공개 운영 봇입니다. 기존 업무 대화는 자동으로 연결하지 않습니다. 봇 설치용 비공개 서버는 본인과 봇만을 위한 공간이며, 서버 메시지를 중계하거나 다른 사용자·서버·채널의 대화를 수집하지 않습니다.

## 처리하는 정보
본인 확인과 응답 연결에 필요한 Discord 사용자·봇·DM·메시지 식별자, 본인 DM 문장과 모델 답변, 질문·권한 요청의 표시 내용과 버튼 선택값, 처리 시각과 오류 상태를 처리합니다. 지원 범위 밖의 요청은 자동 승인하지 않습니다. 비밀번호·인증 코드·복구 코드·비밀키 또는 건강·금융 등 민감정보를 보내지 마세요.

## 이용·전달과 보안
정보는 본인 확인, 문장·응답 전달, 연결 시험과 오류 확인에만 사용합니다. 광고·판매·프로파일링 또는 AI 학습용 수집을 하지 않습니다. 전달된 문장과 필요한 응답은 Discord, 사용자가 연결한 Aside 및 AI 서비스에서 각 서비스 정책에 따라 처리될 수 있습니다.
봇 인증키는 PC에서 Windows CurrentUser DPAPI로 암호화하고 소유자 전용 파일 권한으로 보호합니다. Discord API 식별자 등 상세 기록을 PC에 저장하는 경우 암호화합니다. 중계 코드의 일반 로그에 원문 대화나 인증키를 남기지 않으며, 공개 저장소에는 이 안내 문서만 게시합니다.
정상 로컬 CLI 경로로 전달되는 문장은 실행 인자에 일시 포함될 수 있습니다. 운영체제나 설치된 보안 도구의 수집 여부는 이 앱이 통제하지 못하므로 민감정보를 보내지 마세요.

## 권한 응답
권한 허용은 지원되는 요청의 내용을 본인이 확인하고 DM의 해당 버튼을 직접 선택하는 방식으로만 처리합니다. 일반 DM의 “허용”이라는 문장이나 무응답을 승인으로 취급하지 않으며, 자동 허용·항상 허용·전체 접근 전환을 하지 않습니다. 확인되지 않은 형식은 PC 확인이 필요한 상태로 남깁니다.

## 보관과 삭제·문의
연결 운영·시험·소유자 식별·문제 확인에 필요한 기간에만 보관합니다. 이용자가 삭제를 요청하거나 운영을 종료하거나 더 이상 정보가 필요하지 않으면 해당 앱이 저장한 API 수신 자료를 삭제합니다. Discord와 Aside·AI 서비스 자체의 대화 기록은 각 서비스 정책과 이용자 설정을 따릅니다.
이 앱의 이용자는 소유자 본인으로 한정됩니다. 정정·삭제·연결 해제·문제 신고는 이 앱을 설정한 Aside 대화에서 요청할 수 있습니다.

처리 목적이나 범위를 변경하면 이 문서를 갱신하고 적용 전에 이용자에게 알립니다.
