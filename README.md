# 내 PC 도우미 개인정보 처리방침

시행일: 2026-10-29

## 목적과 이용 대상
이 앱은 앱 소유자 한 명의 개인 PC 연결 시험을 위한 비공개 운영 봇입니다. 본인 DM의 연결 확인, 고정된 질문 응답, 본인이 직접 선택하는 일회성 권한 응답만 시험합니다. 다른 사용자·서버·채널의 대화를 수집하지 않습니다.

## 처리하는 정보
본인 확인과 응답 연결에 필요한 Discord 사용자·봇·DM·메시지 식별자, 버튼 선택값, 질문 응답, 처리 시각과 오류 상태를 처리합니다. 본인 DM에 들어오는 일반 텍스트는 수신될 수 있으나 현재 시험에서는 작업 지시로 전달하거나 본문을 시험 로그에 보관하지 않습니다. 비밀번호, 인증 코드, 건강·금융 등 민감정보를 보내지 마세요.

## 이용·전달과 보안
정보는 본인 확인, 응답 전달, 연결 시험과 오류 확인에만 사용합니다. 광고, 판매, 프로파일링 또는 AI 학습용 수집에 사용하지 않습니다. 필요한 응답은 Discord 및 사용자가 연결한 PC 작업 도구와 AI 서비스에서 각 서비스 정책에 따라 처리될 수 있습니다.
봇 인증키는 개인 자격증명 보관함과 Windows 사용자 단위 암호화로 보호합니다. Discord API에서 받은 식별자 등 상세 기록을 PC에 저장하는 경우 암호화하며, 비밀키나 원문 대화를 공개하지 않습니다.

## 보관과 삭제·문의
연결 시험·소유자 식별·문제 확인에 필요한 기간에만 보관합니다. 이용자가 삭제를 요청하거나 운영을 종료하거나 더 이상 정보가 필요하지 않으면 해당 앱의 API 수신 자료를 삭제합니다. Discord와 연결된 작업 도구 자체의 대화 기록은 각 서비스 정책과 이용자 설정을 따릅니다.
이 앱의 이용자는 소유자 본인으로 한정됩니다. 정정·삭제·연결 해제·문제 신고는 이 앱을 설정한 Aside 대화에서 요청할 수 있습니다.

## 변경
처리 목적이나 범위를 변경하면 이 문서를 갱신하고 적용 전에 이용자에게 알립니다.
